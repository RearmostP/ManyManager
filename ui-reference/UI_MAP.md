Shared colors, spacing, and radii are in Android `res/values/colors.xml`, `res/values-night/colors.xml`, shape drawables, and `res/values/styles.xml`; web `css/tokens.css`, `css/base.css`, and `css/components.css`. Web rendering helpers and icon paths are in `js/render-helpers.js` and `js/icons.js`.

Translations are in Android `res/values/strings.xml`, `res/values-iw/strings.xml`, `res/values-en/strings.xml`, `res/values-ru/strings.xml`, and theme label resources; web `locales/{he,en,ru}.json` and `js/i18n.js`. Web navigation and temporary overlay state are in `js/state.js` and `js/app.js`. The in-memory source/category/expense model is in `js/preview-model.js`; Android uses Application.repository → `PersistentDataViewModel.kt` → `SourceListState.kt` / prepared snapshots. `BudgetViewModel.kt` retains only expansion UI state; the temporary allocation model has been removed. Period boundaries are in Android `domain/BudgetPeriodCalculator.kt`, localized labels in `BudgetPeriodFormatter.kt`, and browser civil-date logic in `js/budget-period.js`.

Maintenance: future Android UI changes should include corresponding `ui-reference/` and `UI_MAP.md` updates.

Limits: Android categories, budget sources, period allocations, and expenses persist in Room SQLite across process restarts; browser preview data remains in JS memory and resets on reload. Android form operations survive ordinary configuration changes in the ViewModel; A Bundle from an interrupted source write locks that form against automatic or manual resubmission and offers review of saved data in the captured period. Fresh operations require deliberate user action; this is not durable operation deduplication. Persistent source/allocation facts survive process death. Browser data resets on reload. The Android expense draft is restored across configuration changes, including while its category dialog is open. Expense saving and amount correction persist on Android; the browser resets them on reload. Expense operation states survive ordinary Activity recreation, and restored uncertain writes cannot be replayed. Amounts must be positive; no expense deletion, refunds or other-field editing are implemented. Browser font metrics, native dialogs, IME, system bars, and ripple effects differ; pixel-level equivalence is unverified.
