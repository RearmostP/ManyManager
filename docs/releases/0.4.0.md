# ההוצאות שלי — גרסה 0.4.0

## מה חדש

- **הדרכת התחלה:** במסך הפתיחה הראשון אפשר להגדיר קטגוריות, תקציב לתקופה ומקורות הוצאה, או לדלג. ההתקדמות נשמרת להמשך.
- **ניהול קטגוריות:** הוספת תתי־קטגוריות ברמה אחת ושינוי שמות של קטגוריות ותתי־קטגוריות תוך שמירה על שיוך ההוצאות הקיימות.
- **תצוגת קטגוריות:** הצגת שמות תתי־קטגוריות יחד עם הקטגוריה הראשית בבחירה ובפירוט ההוצאות.
- **ממשק אחיד יותר:** שיפור עיצוב כפתורי הפעולה וחלונות ההוספה והעריכה, כולל תמיכה במצבי לחיצה ובפעולות שאינן זמינות.
- **אודות:** סעיף חדש בהגדרות המציג את גרסת האפליקציה ואת שם היוצר RearmostP.
- עדכון התצוגה המקדימה והתרגומים בעברית, באנגלית וברוסית.

## הורדה ועדכון

יש להוריד את **ManyManager-0.4.0.apk** המצורף לרליז ולהתקין כעדכון לגרסת ההפצה הקיימת.

- גרסה: **0.4.0**, קוד גרסה: **5**.
- מזהה האפליקציה: `com.example.manymanager`.
- הקובץ חתום במפתח ההפצה הקיים.
- נוסף שדרוג למסד הנתונים מגרסה 2 לגרסה 3 עבור תתי־קטגוריות, עם שמירת הנתונים הקיימים.
- נדרשת Android 11 ומעלה.

## בדיקות

בדיקות היחידה, בדיקת Lint ובניית Release עברו בהצלחה. חתימת ה־APK ומספר הגרסה אומתו. לא בוצעה בדיקת התקנה או שדרוג במכשיר עבור הפצה זו.
