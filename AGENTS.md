- Read current variant documentation first. On `main`, begin with `docs/manymanager/README.md`.
- On `original`, consult `docs/manymanager-simple/` when documentation exists. If it is still empty, inspect actual branch code and ask only when necessary; do not assume ManyManager's rules apply.
- Historical `archive/` documents are not default reading. Read them only for a specific historical question or a missing detail.
- Current confirmed requirements supersede historical plans.
